# AI learning log — index

One log per engineer. Each is written in the brief's format — concept gap, the
exact question asked, the AI guidance, a small experiment on unrelated ground,
independent verification against the real code, and the decision — and each
records at least one AI suggestion that was changed or rejected after being
measured.

Both logs use the project's evidence labels. Every measurement quoted in them
was run in this environment on 2026-10-16; the two bug-hunter tests they refer
to are written up separately in [bug-hunter-tests.md](bug-hunter-tests.md), and
the before-and-after measurements behind both logs are in
[baseline-check.md](baseline-check.md).

The file names keep the spelling the repository already had for these two files;
they are not a typo introduced here.
